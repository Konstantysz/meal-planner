# Design #37 structure prototype (PROTOTYPE, throwaway)

A single self-contained HTML page: plan grid, recipe shelves, recipe page, phone views and a light/dark toggle. Treatment 3 of the style interview (warm neutrals, beetroot brand `#A32E55`). Kept only as a primary source; it is not production code and nothing imports it.

The decisions live in the wiki page [design-brief](../../docs/wiki/concepts/design-brief.md). If this page and the brief disagree, the brief wins.

Open it: double-click `index.html`, or run `start prototypes/design-37-structure-PROTOTYPE-throwaway/index.html` from the repo root. Fonts load from Google Fonts, so it needs a network connection for the intended look.

Delete this directory once #37 has shipped.
